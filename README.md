# نخبة الترميم – موقع الشركة

موقع عربي RTL مبني باستخدام Next.js App Router وTypeScript وTailwind CSS. يتضمن صفحات الشركة والخدمات والمقالات وبيانات SEO وSchema وSitemap وRobots ونموذج تواصل يجهز الطلب عبر WhatsApp.

## المتطلبات
- Node.js 20.9 أو أحدث
- npm

## التشغيل المحلي
```bash
npm install
cp .env.example .env.local
npm run dev
```
افتح http://localhost:3000

## إعدادات ما قبل النشر
1. عدّل `NEXT_PUBLIC_SITE_URL` في `.env.local` إلى الدومين الحقيقي مع https.
2. تحقق من رقم واتساب في `NEXT_PUBLIC_WHATSAPP_NUMBER`. الرقم المدخل في المشروع هو 966574227626 (صيغة دولية دون +).
3. حدّث `NEXT_PUBLIC_PHONE_DISPLAY` إذا كان الرقم المحلي المعتمد مختلفاً.
4. أضف معرف GA4 عند توفره في `NEXT_PUBLIC_GA_ID` (لم تتم إضافة تتبع تلقائي قبل تزويد المعرف وسياسة الخصوصية).
5. أضف صور المشاريع الحقيقية ونصوصها بعد اعتمادها. صفحة الأعمال حالياً لا تدعي وجود مشاريع غير موثقة.
6. راجع محتوى الخدمات والمقالات قانونياً وتجارياً قبل النشر، وأضف تفاصيل النشاط الفعلية وبيانات الترخيص إن رغبت بإظهارها.

## البناء للإنتاج
```bash
npm run build
npm start
```
يمكن نشر المشروع على Vercel أو أي استضافة تدعم Next.js. اربط الدومين من لوحة الاستضافة ثم فعّل HTTPS.

## Google Search Console
1. أضف الموقع كـ Domain property في Google Search Console.
2. تحقق من الملكية عبر سجل DNS لدى مزود الدومين (موصى به).
3. بعد النشر افتح `https://YOUR-DOMAIN/sitemap.xml` وتأكد من ظهوره.
4. أرسل `sitemap.xml` من قسم Sitemaps في Search Console.
5. استخدم URL Inspection لفحص الصفحة الرئيسية والصفحات الخدمية المهمة ثم اطلب الفهرسة.
6. راقب تقارير Pages وCore Web Vitals وSearch results بمرور الوقت. الفهرسة والترتيب لا يمكن ضمانهما بمجرد إنشاء الموقع.

## ملاحظات مهمة
- لم تتم إضافة قاعدة بيانات أو لوحة إدارة؛ المحتوى الحالي معرف في `lib/site.ts` ويمكن تعديله برمجياً. أضف CMS وقاعدة بيانات إذا كان فريق الشركة سيحدث المقالات والمشاريع باستمرار.
- نموذج التواصل يفتح WhatsApp ولا يخزن بيانات العملاء على الخادم.
- رقم الهاتف المعروض في brief كان 574227626؛ تم تطبيعه إلى +966574227626. تحقق من أنه الرقم الصحيح قبل النشر.
- عنوان الدومين الافتراضي `example.com` يجب تغييره قبل النشر حتى تكون canonical وSitemap صحيحتين.
